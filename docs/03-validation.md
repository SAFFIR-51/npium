# 구현 및 검증
2026-10-14

- JavaScript 및 로컬 서버 구문 검사 통과.
- 로컬 HTTP 200 확인.
- Chromium에서 375px / 768px / 1440px 가로 넘침 없음.
- 전체 6개, 예능 3개, 교양·다큐 1개, 디지털 2개 필터 확인.
- 사업 3개, 프로그램 6개, 인물 3개, 프로젝트 3개 상세 열기 및 Escape 닫기 확인.
- 인도네시아 선택 시 현지 파트너 설명 표시 확인.
- 모바일 메뉴 열기 및 링크 선택 후 닫기 확인.
- 모든 이미지 로딩 및 브라우저 JavaScript 오류 없음 확인.
- 데스크톱·모바일 전체 페이지 캡처를 시각 검토.
- 문의 기능은 이메일 앱 연결 방식. 실제 이메일 발송은 수행하지 않음. 클립보드는 실행 브라우저 권한에 따라 안내 문구로 대체.

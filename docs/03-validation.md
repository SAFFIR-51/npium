# V2 검증 — 2026-10-14
- 9개 HTML 페이지 × 375 / 768 / 1440px = 27개 반응형 조합 검사 통과.
- 내부 페이지 링크 HTTP 200, 모든 이미지 로딩, 가로 넘침 없음 확인.
- 메인 비주얼 PEOPLE / CULTURE 선택에 따라 이미지 변경 확인.
- 참여 경력 4개 필터, 상세 모달 및 Escape 닫기 확인.
- 사업 모달에서 해당 사업 독립 페이지 링크 연결 확인.
- 국가 탭, 문의 FAQ, 이메일 작성 안내, 모바일 메뉴로 페이지 이동 확인.
- prefers-reduced-motion에서 스크롤 등장 모션 비활성화 확인.
- 최종 브라우저 실행 오류 없음. 메인 데스크톱·모바일과 미디어·포트폴리오 전체 페이지를 스크롤 후 캡처하여 시각 검토.
- 브라우저 기본 페이지 전환은 반복 이동 시 중단 오류가 발생하여 제거하고 명시적인 화면 전환으로 대체. 뒤로 가기 복원 시 전환 레이어 초기화.
- 이미지 자산 1.03MB로 최적화. 클라이언트 외부 의존성 없음.

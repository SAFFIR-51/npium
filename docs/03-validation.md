# 모바일 내비게이션 수정 — 2026-10-15
사용자 보고: 햄버거 메뉴에서 페이지 선택 후 보라색 화면이 남음.

페이지 링크의 기본 동작을 preventDefault로 중단하고 보라색 레이어를 표시한 뒤 location.assign으로 이동하던 코드를 제거했다. 모든 페이지 생성물에서 전환 레이어 DOM을 제거하고 잔여 캐시와 혼용되어도 표시되지 않도록 CSS에서 비활성화했다. 내비게이션은 일반 앵커의 기본 이동을 사용한다. 나머지 콘텐츠 및 WebGL 효과는 유지한다.

인앱 브라우저 375px에서 햄버거 메뉴를 통해 About → Business → Experience → Global 이동, 현재 Global 재선택, 뒤로 가기 확인. 각 목적지 제목/경로, 메뉴 닫힘, 전환 레이어 부재 확인. 전체 JavaScript 구문 검사 통과.

# 콘텐츠 표시 복구 — 2026-10-16
사용자 캡처에서 02 사업 카드, 03 참여 경력 카드, 05 프로젝트 행의 빈 영역 확인. 등장 전에 clip-path/opacity로 숨긴 상태를 IntersectionObserver의 진입 감지에 의존하던 구조를 수정했다. 모든 콘텐츠는 기본적으로 표시하고, 화면 진입 후 일회성 CSS keyframe만 재생한다. 감지가 누락되거나 중단되어도 내용은 남는다.

브라우저에서 사업 3개, 경력 6개, 프로젝트 3개의 기본 opacity=1/clip-path=none 확인. 사업 카드 스크롤 진입 후 is-visible과 최종 마스크 펼침 상태 확인 및 실제 이미지·본문 시각 검토. JavaScript 구문 검사 통과.

# 직접 문의 전송 / 디자인 — 2026-10-16
공통 문의 영역을 연한 라벤더 바탕과 흰색 폼 카드로 재구성. 불필요한 대형 배경 글자를 제거하고 레이블·입력란·포커스·자동완성 대비를 보강했다. 이름, 선택 회사명, 회신 이메일, 문의 분야, 문의 내용, 동의 입력을 구성했다.

이메일 앱 연결 submit을 제거하고 FormSubmit AJAX API로 전송. 수신 주소는 planova.develop@gmail.com 고정. 전송 중 중복 클릭 방지, 20초 제한, 성공/오류 상태, 오류 시 입력값 보존, 글자 수 표시, 허니팟 추가. 개인정보 전송 서비스 안내 제공. 성공 응답은 메일함 최종 도착 자체의 보장이 아니며 수신자 최초 활성화가 필요하다.

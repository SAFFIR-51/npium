# 설계
## 방문자와 목적
방송·디지털 콘텐츠 발주 담당자, 기업·지자체 행사 담당자, 해외 파트너가 사업 범위와 제작진 경험을 확인하고 이메일 문의로 이동한다.
## 정보 구조
홈(브랜드) → About(철학) → Business(3개 사업, 클릭 상세) → Selected Experience(필터, 상세) → Global Network(국가별 역할) → Next Projects(계획 상태) → Contact.
## 시각 체계
배경 #101014, 텍스트 #f4f1ee, 보조 #aaa5b1, 포인트 #bb96ff. 원본 보라색을 절제된 편집 디자인으로 확장. 대형 영문/국문 제목, 얇은 구분선, 비대칭 그리드, PPT 카메라 이미지 사용. 시스템 폰트로 외부 폰트 의존 없음.
## 상호작용
고정 내비게이션, 모바일 메뉴, 사업 상세 모달, 장르별 포트폴리오 필터, 프로그램/작가 상세 모달, 국가 선택, 문의 내용 작성 후 이메일 앱 열기, 이메일 복사. 백엔드가 없는 이메일 방식임을 사용자에게 명확히 안내. 입력 내용 전송·저장 없음.
## 접근성과 반응형
의미 있는 헤딩, skip link, 명시적 버튼 이름, aria-expanded/pressed, 모달 초점 이동·복원·Escape 닫기, reduced-motion, 375/768/1440 화면 검토. 타깃 44px 이상.
## 구현
빌드 없는 HTML/CSS/JavaScript. dist를 직접 배포. 외부 API 및 외부 이미지 의존 없음. 문서와 원본 분석은 dist 밖에 보관.

# V2 — 다중 페이지와 모션 확장
요청: 더 역동적인 연출과 추가 페이지.

## 페이지 구조 (총 9개)
- index.html: 전체 화면 메인 비주얼, 직접 선택하는 3개 이미지, 대형 윤곽 타이포그래피, 브랜드 마키, 전체 사업 요약.
- about.html: 회사 관점, 브랜드 메시지, 대표·협업 작가 경력.
- business.html: 사업 소개 및 세 상세 페이지로 이동.
- media.html: 방송·디지털·기획 업무와 관련 참여 경력.
- agency.html: 해외 인재·무역·현지 운영, 국가별 역할과 4단계 업무 체계.
- culture.html: 페스티벌·인재 양성·문화 파트너십과 계획 단계 프로젝트.
- work.html: 장르별 필터, 참여 경력 이미지 및 상세 정보.
- global.html: 한국·베트남·인도네시아 업무 및 소개서상 현지 파트너.
- contact.html: 이메일 문의, 작성 안내, FAQ.

## 모션 체계
첫 화면 텍스트 등장, 이미지 전환, 스크롤 진행 표시, 이미지 패럴랙스, 요소별 스크롤 등장, 포인터를 따라가는 커서와 카드 광원·기울기, 네트워크 궤도 회전과 노드 부유, 페이지 간 전환, 이미지 호버 오버레이. IntersectionObserver로 보이는 요소만 등장 처리. 포트폴리오 필터 후 새 카드도 관찰. 페이지 링크를 누르면 짧은 화면 전환 후 이동하며, 뒤로 가기 복원 시 전환 레이어를 초기화. 모바일에는 커서·기울기 효과 제외. prefers-reduced-motion에서는 반복 애니메이션·패럴랙스·커서·전환 비활성화.

## 성능
PPT의 대형 이미지들을 최대 1920px WebP로 변환. 자산 합계 약 32MB → 1.03MB. 로고는 원본 PNG 유지. 이미지는 지연 로딩을 사용하며 메인 이미지 전환은 다음 이미지 로딩 완료 후 수행.

# V3 — In connection: 공간과 초점
사용자 레퍼런스: https://unicorn.studio/remix/7DIuHuo4fP8MePw7ufQ5 (IN FOCUS). 실제 페이지에서 부유 이미지, 종이 같은 곡면 변화, 깊이와 중앙 텍스트의 흐림을 시각 확인했다. 레퍼런스 소스나 자산은 복제하지 않고 제공된 자료 이미지로 독자 구현했다.

- WebGL vertex mesh로 이미지 면을 분할하고 사인 곡면과 3축 회전을 적용.
- 원근 투영, 깊이별 크기·블러, 포인터의 지연 시차로 공간감 구성.
- 메인: MEDIA/PEOPLE/CULTURE 선택 시 장면 이미지와 배경 분위기 변경.
- 회사 소개/포트폴리오/홈: In connection 입체 갤러리. 참여 경력 포함 이미지임을 표시.
- 사업별 상단: 미디어 시트, 문화 색감, 해외 네트워크 그리드·광환으로 차별화.
- 스크롤: 초점 선명화, 가로 커튼, 원형 열림, 가로 선, 입체 셔터, 스케일 조합.
- 회사 철학 문장: 스크롤 위치에 따른 잉크 채움 마스크.
- 서비스 이미지: 스크롤 연동 프레임 열림·기울기·빛 스윕.
- 버튼: 포인터를 따라오는 자석 반응.
- 장면별 모션 정지·재생 버튼. 세션 내 정지 상태 유지. reduced-motion에서는 정적 장면과 텍스트로 표시.
- 화면 밖/비활성 탭에서는 WebGL 프레임 중단. 모바일은 메시·카드 수와 DPR 축소.
- WebGL 미지원/컨텍스트 손실 시 정적 CSS 배경으로 전환. 원본 이미지와 콘텐츠는 접근 가능한 DOM으로 유지.

외부 Unicorn 런타임, 원격 프로젝트, 유료 라이선스 및 외부 스크립트에 의존하지 않는다.

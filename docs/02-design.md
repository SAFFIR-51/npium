# 설계
## 방문자와 목적
방송·디지털 콘텐츠 발주 담당자, 기업·지자체 행사 담당자, 해외 파트너가 사업 범위와 제작진 경험을 확인하고 이메일 문의로 이동한다.
## 정보 구조
홈(브랜드) → About(철학) → Business(3개 사업, 클릭 상세) → Selected Experience(필터, 상세) → Global Network(국가별 역할) → Next Projects(계획 상태) → Contact.
## 시각 체계
배경 #101014, 텍스트 #f4f1ee, 보조 #aaa5b1, 포인트 #bb96ff. 원본 보라색을 절제된 편집 디자인으로 확장. 대형 영문/국문 제목, 얇은 구분선, 비대칭 그리드, PPT 카메라 이미지 사용. 시스템 폰트로 외부 폰트 의존 없음.
## 상호작용
고정 내비게이션, 모바일 메뉴, 사업 상세 모달, 장르별 포트폴리오 필터, 프로그램/작가 상세 모달, 국가 선택, 문의 내용 작성 후 이메일 앱 열기, 이메일 복사. 백엔드가 없는 이메일 방식임을 사용자에게 명확히 안내. 입력 내용 전송·저장 없음.
## 접근성과 반응형
의미 있는 헤딩, skip link, 명시적 버튼 이름, aria-expanded/pressed, 모달 초점 이동·복원·Escape 닫기, reduced-motion, 375/768/1440 화면 검토. 타깃 44px 이상.
## 구현
빌드 없는 HTML/CSS/JavaScript. dist를 직접 배포. 외부 API 및 외부 이미지 의존 없음. 문서와 원본 분석은 dist 밖에 보관.

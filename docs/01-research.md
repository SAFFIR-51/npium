## 대조 결과와 콘텐츠 원칙
PDF 텍스트에는 일부 이미지화된 제목과 이메일이 누락되며 PPT 텍스트와 시각 검토로 보완했다. 대표와 작가의 과거 참여 경력을 nPIUM 법인의 단독 제작 실적으로 표현하지 않는다. 2026/2027 계획은 자료 작성 당시 상태이며 확정 일정/모집을 제공하지 않는다. 비자는 원문 업무 범위 식별자로만 취급하고 자격/절차/발급 가능성을 안내하지 않는다. 사업자번호, 주소, 전화, 고객 실적 수치, 수상 정보는 미제공이므로 생성하지 않는다.

## 공식 사이트 레퍼런스
1. [CJ ENM](https://www.cjenm.com/ko/): 브랜드 메시지 → 사업 영역 → 대표 콘텐츠의 탐색 흐름. 다수의 사업을 3개 축으로 정리하는 구조를 적용. 문구·이미지 복제 없음.
2. [Studio Dragon 회사 소개](https://www.studiodragon.net/ko/about/company/): 회사 정체성과 작품/제작 역량 분리. 참여 경력을 별도 섹션으로 표시. 조사 검색 결과 확인; 직접 페이지 열기는 오류 발생.
3. [HSAD](https://www.hsad.co.kr/eng/main): Work / Capability / About / Contact로 분리한 작업 중심 탐색. 카드 클릭 상세와 간결한 문의 동선 적용.
4. [KOTRA 사업 소개](https://kotra.or.kr/subList/20000005984): 해외진출·전시·시장조사의 서비스 분류 방식 참고. nPIUM과 관계를 의미하지 않음.
5. [한국관광공사 대구치맥페스티벌](https://korean.visitkorea.or.kr/kfes/detail/fstvlDetail.do?Flag=Y&cmsCntntsId=1801011): 축제 공식 주최·운영 및 프로그램의 구분을 확인. 원본의 해외 축제 구상을 기존 대구 행사 개최 실적으로 해석하지 않음.

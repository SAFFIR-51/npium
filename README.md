# nPIUM 웹사이트
회사소개 PPT/PDF를 상세 검토하고 공식 사이트 레퍼런스를 조사하여 구현한 한국어 반응형 기업 사이트.

## 실행
Node.js 18 이상에서 `npm run dev`, http://127.0.0.1:4173 접속. 의존성 설치/빌드 불필요. `npm run check`로 JavaScript 구문 검사. 배포 디렉터리 `dist/`.

## 문서
- docs/01-research.md: 15페이지별 분석, 원본 대조, 공식 레퍼런스 및 적용 이유
- docs/02-design.md: 방문자, 정보 구조, 디자인, 접근성 및 인터랙션 설계
- docs/03-validation.md: 구현 검증 결과

## 구현 범위
고정 내비게이션, 모바일 메뉴, 사업 소개 상세, 6개 참여 경력 및 장르별 필터, 대표·작가 경력, 국가별 업무, 프로젝트 상태 상세, 이메일 복사와 이메일 앱 문의.

문의는 mailto 방식으로 사용자 이메일 앱에서 발송한다. 서버 저장·자동 발송은 구현하지 않았다. 프로그램 경력은 대표·협업 작가 기준이며 법인 단독 제작 실적으로 표시하지 않는다. 축제와 콩쿠르는 소개서상 계획/협의 상태로 표시한다.

## 운영 전 확인 항목
원본 내 프로그램·사업 이미지의 공개 사용 권한, 대표·작가 참여 범위, 프로젝트 최신 진행 상태, 해외 협력 현황과 문의 이메일을 확인한다. 원본 MOU/서명 이미지와 회사소개 파일 전체는 배포하지 않는다. 주소·전화·사업자 정보는 자료에 없어 추가하지 않았다.

## V2: 다중 페이지 / 모션
총 9페이지. 홈, 회사 소개, 사업 안내, 미디어, 에이전시, 문화 콘텐츠, 참여 경력, 글로벌 네트워크, 문의.
`npm run build`로 `scripts/home-template.html`과 `scripts/build-pages.py`에서 HTML을 재생성한다. 디자인은 `dist/style.css`, 공통 기능은 `dist/app.js`, 모션은 `dist/motion.js`에 있다. 메인 비주얼은 사용자가 직접 전환한다. 브라우저 모션 감소 설정을 존중하며 모바일에서는 포인터 효과를 적용하지 않는다.

WebP 이미지 최적화로 이미지 자산 용량을 약 97% 줄였다. `qa/check-v2.cjs`는 9개 페이지를 3개 뷰포트에서 확인하고 필터·상세·내비게이션·문의·모션 감소를 검증한다.

## V3: WebGL 공간 연출
`dist/experience.js`는 원본 이미지 자산을 사용하는 독립 WebGL 연출이다. 곡면 이미지, 원근감, 깊이 블러, 포인터 시차와 사업별 분위기를 구현한다. 홈/회사 소개/참여 경력에는 별도 입체 갤러리가 있다. 효과는 `dist/style.css`의 V3 부분에 정의되며 제목 초점·마스크·입체 셔터·문장 채움으로 구분된다. 장면의 MOTION 버튼으로 자동 움직임을 정지할 수 있다. 외부 라이브러리·Unicorn 프로젝트에 의존하지 않는다.
